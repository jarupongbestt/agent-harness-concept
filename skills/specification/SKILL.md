# Specification

Convert intent into a Ticket or Plan that can be verified.

- State the requested outcome, change type, scope, assumptions, and exclusions.
- Express behavior as observable acceptance criteria with concrete evidence.
- Separate requirements from implementation preferences.
- Identify affected files, interfaces, data, permissions, and regression risk.
- Mark ambiguity explicitly; do not hide a material decision inside an
  implementation step.

Every criterion must be traceable to a test, check, inspection, or explicit user
decision.
