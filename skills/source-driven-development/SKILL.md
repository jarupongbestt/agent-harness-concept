# Source-Driven Development

Use evidence appropriate to the claim.

- Read repository instructions and the narrow relevant source before planning.
- For platform behavior, use current first-party documentation or verified host
  diagnostics; do not promote familiar example paths into facts.
- Record the source, date, applicable platform/version, finding, confidence, and
  verification evidence for material mappings.
- Keep external raw material separate from derived conclusions and internal
  discoveries.
- If evidence is missing, stale, contradictory, or low confidence, mark the
  finding unknown or blocked and stop the dependent decision.
